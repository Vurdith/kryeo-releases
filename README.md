# Kryeo releases

Installers and automatic updates for Kryeo, the desktop app that turns Affinity designs into Roblox Studio UI.

Download the latest `Kryeo-Setup-<version>.exe` from [Releases](https://github.com/Vurdith/kryeo-releases/releases/latest). Once installed, Kryeo updates itself from here.
